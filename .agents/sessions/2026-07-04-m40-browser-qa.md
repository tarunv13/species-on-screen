# Session diary — M40 browser QA (D8): behavioral acceptance verified

**Date:** 2026-07-04
**Milestone:** M40 (Observatory v2, D8 — history-as-trace + interrogation state in URL)
**Role:** Principal Engineer (verification)
**Branch:** `feat/exploration-prototypes-and-data-pipelines`

---

## Why this session

M40 was marked CLOSED, but its acceptance was **behavioral** (deep-link restore, back/forward
retrace, subject+fragment coexistence) and had only ever been verified **headlessly** — a
15-check unit test on the pure `scripts/interrogation-url.mjs` mapping plus `node --check` on the
extracted inline script. The actual runtime behavior in a browser had never been observed; the
audit tracked this as roadmap item **R1** (browser QA). Treating that unverified acceptance as the
genuine remaining work, this session ran the browser QA and confirmed whether the existing
implementation satisfies the criteria (goal step 2). It does; no code change was required
(goal step 3 not triggered).

## Method

- Served the production build: `npm run build` (green) → `vite preview --port 4173`
  (`http://localhost:4173/species-on-screen/`).
- Drove the EPR evidence ledger (`evidence/epr-vents.html`, 10 `id="claim-N"` reveals + the inline
  restore script) in a real browser, asserting DOM/history state after each interaction (not just
  screenshots — `details.open` sets, `location.hash`, `history.length`).

## Results — all four M40 criteria pass

1. **Deep-link restore on load.** `…#claim-3` → only `claim-3` open; `…?subject=east-pacific-rise#claim-7`
   → only `claim-7` open. ✅
2. **Opening writes the fragment as a history entry.** A real `summary` click on `claim-5` set
   `location.hash = "#claim-5"` and added **exactly one** history entry (`history.length` +1);
   the previously-open claim auto-closed. ✅
3. **Back/forward retraces.** `history.back()` → `#claim-3`, `claim-3` re-opened, `claim-5` closed;
   `history.forward()` → `#claim-5`, `claim-5` re-opened. The reasoning path is retraceable. ✅
4. **Subject + interrogation coexist; copied URL restores all three.** Loading
   `?subject=east-pacific-rise#claim-7` restored **subject** (query preserved), **depth** (the
   evidential ledger page), and **interrogation** (claim-7 open). The ascent links carried
   `?subject=east-pacific-rise` to the cinematic, atlas, and research surfaces (M39 coexistence,
   confirmed present). Closing the claim dropped the fragment (`location.hash = ""`) while
   **preserving** `?subject=east-pacific-rise` (`location.search` unchanged). ✅

## Outcome

M40's behavioral acceptance is now verified end-to-end in a browser, not merely asserted from
unit tests. The existing implementation satisfied every criterion; **no code was modified**.
Roadmap **R1**'s primary (M40) component is closed; the remaining R1 items are view-transition /
animation polish (M36 pulse, M37/M39 morph, M28 easing). Per protocol, stopped after M40 passed
verification; did not proceed to any other item.
