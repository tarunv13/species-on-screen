# Ratification records

One dated record per ratified (or escalated) Q1–Q5 question, issued via the
Delegated Ratification Framework (`docs/RATIFICATION_FRAMEWORK.md`) over
evidence collected under `docs/VALIDATION_PROTOCOL.md`.

**Naming:** `YYYY-MM-DD-<question>.md` (e.g. `2026-08-15-q1.md`).

**ACCORD fields** (each record carries all six):

- **Consensus definition** — what agreement meant for this question (which
  pre-committed rule governs it).
- **Evidence read** — the specific logged evidence, quoted verbatim.
- **Rule fired** — the exact pre-committed rule and threshold applied.
- **Critic challenges + resolution** — every challenge the Adversarial
  Questioner raised and how each resolved (or that it forced escalation).
- **Verdict** — the outcome.
- **Escalated (Y/N)** — whether the human steward was required.

A D4–D6 status in `docs/PRODUCT_DECISIONS.md` changes only when, and only as,
a record here dictates. This directory is empty of records until real
evidence exists; no record is written speculatively.
